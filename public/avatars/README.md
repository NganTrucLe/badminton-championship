# Avatar photos

Drop player photo JPGs here, named to match the paths referenced in
`lib/tournament/data.ts` (e.g. `trung-avatar.jpg`, `minhanh-avatar.jpg`, ...).

These files are **not required** — every player component falls back to a
colored circle with initials (matching the original design's `hasPhoto` /
`noPhoto` branching) when the file is missing. Add real photos later;
no code changes needed beyond dropping the JPG in this folder.
