# shadcn/ui Visual Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the entire Badminton Championship app from ad-hoc inline `style={{}}` objects to a shadcn/ui + Tailwind v4 component system, mapped onto the existing cream/green/gold palette, with `lucide-react` icons and `motion` + `tw-animate-css` animation.

**Architecture:** shadcn primitives live in `components/ui/` (CLI-generated, New York style). A `cn()` util (`lib/utils.ts`) merges classes. The existing `globals.css` design tokens are re-expressed as shadcn semantic tokens (`--background`, `--primary`, `--card`, …) so shadcn components adopt the badminton look automatically. Every screen is restyled screen-by-screen behind a passing build and a commit. Interactive components (referee scoring, admin editors, lifecycle) get **characterization tests written BEFORE their restyle** so behavior is locked; leaf visual components get render smoke tests. `motion` adds section reveals and hover polish as a final pass per surface.

**Tech Stack:** Next.js 16.2, React 19.2, TypeScript 5, Tailwind v4 (`@tailwindcss/postcss`), Vitest 4 + Testing Library, Supabase (`@supabase/ssr`), shadcn/ui (New York), `lucide-react`, `motion`, `tw-animate-css`, `class-variance-authority`, `clsx`, `tailwind-merge`.

## Global Constraints

- **Tailwind is v4** — no `tailwind.config.js`. Theme lives in `app/globals.css` via `@import "tailwindcss"`, `:root`, and `@theme inline`. shadcn's `components.json` must use `"tailwind": { "config": "" }`.
- **Path alias:** `@/*` → `./*` (from `tsconfig.json`). shadcn aliases resolve to `@/components`, `@/components/ui`, `@/lib/utils`, `@/hooks`.
- **`npm run build` MUST pass before every commit** (project CLAUDE.md — a broken build is never committed).
- **Preserve all behavior:** Supabase realtime (`useLiveMatches`), optimistic updates + rollback (referee panel), RLS zero-row detection (`.select()` after mutations), write-phase gating (`editable = status === "setup"`), auth gating. Restyle is visual only — no data-layer changes.
- **UI copy stays Vietnamese**, verbatim. Do not translate or reword any user-facing string.
- **Keep `next/font` setup** (`--font-archivo` body, `--font-bricolage` display, `--font-jetbrains` mono). shadcn components must inherit these, not import their own fonts.
- **Commit style:** atomic, title only, `type(scope): what changed`, scope `web`/`admin`/`ui`. Commit under the user's git identity, never Claude's.
- **Palette (must survive the migration, from `globals.css`):** bg `#f4f1e6`, cream `#fffdf7`, primary `#0b5d4e`, primary-dark `#08483c`, dark `#0a1f1a`, gold `#f2b544`, gold-light `#ffc85c`, live/destructive `#ff5a47`, border `rgba(10,31,26,.12)`, text `#0a1f1a`, text-muted `#5b7a72`.

"use client";

import { useState } from "react";
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";
import { cn } from "@/lib/utils";

function initialsOf(name: string): string {
  const parts = name.trim().split(/\s+/).filter(Boolean);
  if (parts.length === 0) return "?";
  if (parts.length === 1) return parts[0].slice(0, 2).toUpperCase();
  return `${parts[0][0]}${parts[parts.length - 1][0]}`.toUpperCase();
}

export function PlayerAvatar({
  name,
  avatarUrl,
  size = 48,
  className,
}: {
  name: string;
  avatarUrl?: string | null;
  size?: number;
  className?: string;
}) {
  const [errored, setErrored] = useState(false);
  const showImg = avatarUrl && !errored;
  return (
    <Avatar className={cn("border border-border bg-secondary/30", className)} style={{ width: size, height: size }}>

      ) : null}
      <AvatarFallback className="bg-secondary text-secondary-foreground font-black" style={{ fontSize: Math.round(size * 0.32) }}>
        {initialsOf(name)}
      </AvatarFallback>
    </Avatar>
  );
}
